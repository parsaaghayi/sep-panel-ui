# Progressbar Component

کامپوننت Progressbar یک نوار پیشرفت ساده برای نمایش درصد تکمیل یک فرآیند (مثل بارگذاری یا تکمیل فرم) در پروژه‌های React است.

## ویژگی‌ها

- ✅ نمایش درصد پیشرفت با مقدار عددی ۰ تا ۱۰۰
- ✅ تغییر خودکار رنگ نوار در تکمیل کامل (۱۰۰٪) به سبز
- ✅ نوع امن TypeScript — فقط اعداد صحیح ۰ تا ۱۰۰ پذیرفته می‌شود
- ✅ طراحی مطابق با UI Kit

## نحوه استفاده

```tsx
import { Progressbar } from "@parsaaghayi/sep-panel-ui";

function MyComponent() {
  return <Progressbar filled={50} />;
}
```

## Props

| Prop     | Type     | Default | Description                                        |
| -------- | -------- | ------- | -------------------------------------------------- |
| `filled` | `number` | -       | درصد پیشرفت نوار — عدد صحیح بین ۰ تا ۱۰۰ (اجباری)  |

## مثال‌های استفاده

### نوار خالی

```tsx
<Progressbar filled={0} />
```

### نیمه‌پر

```tsx
<Progressbar filled={50} />
```

### تکمیل کامل

```tsx
<Progressbar filled={100} />
```

## نکات مهم

1. مقدار `filled` باید عدد صحیح بین ۰ تا ۱۰۰ باشد؛ در TypeScript مقادیر خارج از این بازه خطای کامپایل می‌دهند
2. در مقادیر کمتر از ۱۰۰ رنگ نوار `#42526E` و در مقدار ۱۰۰ رنگ آن به سبز `#36B37E` تغییر می‌کند
3. این کامپوننت فقط نوار پیشرفت را نمایش می‌دهد و متن درصد را نشان نمی‌دهد
